## Mentor Q&A ammo

- **"Isn't this just prompting?"** → capability separation matrix + the promote() policy function — no model call can turn a passport green. Show the mutation guard.
- **"Is this staged?"** → real external merchants (consent logged), mentor-supplied unseen intention, real live-mode event. Offer: "give me a buyer intention right now."
- **"Which agent spent the most today?"** → answer from the control room's cost filter, not from memory.
- **"How do you know v4 beats v1?"** → eval pass-rate + time-to-fix trend, failures auto-captured as evals.
- **"What if the model hallucinates a fix?"** → agents can only write a Zod-validated SiteSpec; the deterministic verifier replays the exact contract; promotion is policy code.
- **"What counts as one task for overflow?"** → one complete verified launch OR one complete guardian incident independently reverified (bible §23) — not probes, steps, or drills.

## Live-flake protocol (stay truthful)

1. Deterministic runner retries once automatically.
2. Second failure → say so plainly, show the recorded passing trace of the same contract **labeled as a recording**, and offer the already-green site for live poking.
3. Never re-narrate a failure as a success; a caught failure that becomes an eval on stage is itself a scoring moment (§15).

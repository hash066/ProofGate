# Axcas final beta acceptance

This is the smallest honest launch run. It requires no customer API keys, cloud account, storage account, or developer setup.

1. Open the live Studio and choose **Both**.
2. Click **Continue with WhatsApp** and send the prefilled message from a recipient already allowed on Meta's test number.
3. Add one business name, description, offering with price, order number, and at least one real photo.
4. Build the website, inspect the private preview, tick the single publish checklist, and publish.
5. Build a reel, choose one of the three suggestions, tick the single reel checklist, and wait for the private MP4 download.
6. Open the published mobile page, tap the tracked WhatsApp CTA, and request the metrics summary.
7. For Vapi only, give an explicit self-test number and consent. Complete one call by declining recording and one by accepting; confirm that decline creates no recording and that “do not call” revokes future consent.

Do not treat a code test, synthetic webhook, local render, or operator click as this acceptance.
